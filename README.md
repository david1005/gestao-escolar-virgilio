# Sistema de Gestão Escolar

## 1. O que é o sistema

O Sistema de Gestão Escolar é uma aplicação web desenvolvida para auxiliar a organização administrativa e pedagógica da EEEP Governador Virgílio Távora.

O sistema centraliza informações de alunos, turmas, registros de atrasos, saídas antecipadas, ocorrências escolares, usuários, permissões, relatórios, anexos e backups.

## 2. Para que ele serve

O sistema tem como objetivo facilitar o acompanhamento da rotina escolar, permitindo que a equipe registre, consulte e organize informações importantes de forma mais rápida, segura e centralizada.

Ele ajuda a escola a:

- controlar dados dos alunos;
- organizar alunos por curso e turma;
- registrar atrasos e saídas antecipadas;
- emitir autorizações de entrada e saída;
- registrar ocorrências escolares;
- gerar termos e relatórios;
- acompanhar indicadores no dashboard;
- controlar permissões de acesso por perfil;
- manter histórico e auditoria das ações realizadas;
- gerar backups do banco de dados e dos anexos.

## 3. Tecnologias usadas

O projeto foi desenvolvido utilizando:

- Python
- FastAPI

- Jinja2
- HTML
- CSS
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Uvicorn
- Git e GitHub

## 4. Funcionalidades

Principais funcionalidades do sistema:

- login de usuários;
- controle de permissões por perfil;
- cadastro, edição e consulta de alunos;
- cadastro de cursos e turmas;
- importação de alunos por arquivo CSV/Excel;
- pré-visualização antes da importação;
- exportação de alunos;
- controle de ano letivo;
- virada automática de ano letivo;
- histórico de matrícula do aluno;
- linha do tempo do aluno;
- registro de atrasos;
- registro de saídas antecipadas;
- impressão de autorização de entrada;
- impressão de autorização de saída;
- cadastro de ocorrências escolares;
- impressão de termo de ocorrência;
- anexos em alunos, registros e ocorrências;
- dashboard com indicadores;
- relatórios oficiais para impressão/PDF;
- tela de configurações;
- backup do banco de dados;
- backup dos anexos;
- auditoria das ações realizadas;
- modo escuro;
- manual do usuário integrado.
